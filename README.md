# MINI BABY

موقع بداية لمتجر **MINI BABY**: واجهة عربية متجاوبة، كتالوج منتجات ومقاسات، بحث وتصنيفات، سلة محفوظة على الجهاز، طلب عبر واتساب، ودمية ثلاثية الأبعاد قابلة للتدوير لمعاينة ألوان وقصّات الملابس.

## تشغيل الموقع

افتح `index.html` في متصفح حديث مع اتصال بالإنترنت؛ مكتبة Three.js الخاصة بالدمية تُحمّل من jsDelivr. إذا تعذر تحميلها، يظهر الرسم التوضيحي الاحتياطي.

## إضافة معلومات المحل والمنتجات

1. افتح `store.js` وعدّل `currency` ورقم `whatsappNumber` بصيغة دولية مع رمز الدولة، من دون `+` أو مسافات (مثال تنسيقي: `9627XXXXXXXX`).
2. استبدل المنتجات التجريبية في `products` بمعلومات القطع الحقيقية: `name`, `description`, `sizes`, `price`, `color` و`outfit`.
3. أضف صور المنتجات إلى `assets/products/`، ثم ضع مسار كل صورة في الخاصية `image` مثل `assets/products/cotton-set.jpg`. اتركها فارغة مؤقتًا إذا لم توجد صورة. لإضافة صور أخرى للقطعة نفسها (مثل صورة مقرّبة للقماش) ضع مساراتها في `gallery`، وستظهر كصور مصغّرة تحت الصورة الرئيسية. يمكن أيضًا ربط صور محددة بكل لون عبر الخاصية `photos` داخل اللون في `colors`.
4. استبدل `assets/logo.svg` بشعار المحل عند توفره. للحفاظ على الاسم الظاهر في الصفحة، عدّل النص `MINI BABY` في `index.html` إذا تغيّر.
5. ارفع التعديلات إلى مستودع GitHub. بعد ربط المستودع بـ Claude Code يمكن طلب تعديل المنتجات أو التصميم من هناك.

صور اللون الأسود والأحمر والسكني المرفقة مقصوصة إلى صور مستقلة ومربوطة بخيارات الألوان. صورة السكني الجديدة تتضمن عرضًا أماميًا وخلفيًا وصورًا مقرّبة للحياكة والكمّ. لا توجد صورة فعلية للبيج، لذلك يظهر هذا اللون كتوضيح على الدمية مع تنبيه بدل عرض صورة لون مختلف على أنه بيج. الدمية مصممة بطول تقريبي 75 سم ومحيط صدر تمثيلي يقارب 47 سم لطفل حول عمر سنة؛ هذه أرقام توضيحية وليست قياسًا طبيًا أو جدولًا معياريًا. طقم الصوف له نموذج ثلاثي الأبعاد يغطّي الجذع والكمّين والساقين، مع نسيج حياكة بارز وأشرطة مضلّعة وأزرار. النموذج معاينة مجسّمة مصممة للموقع، وليس مسحًا مطابقًا للقطعة أو محاكاة فيزيائية كاملة للقماش؛ القطع الجديدة تحتاج نموذجًا يناسب قصّتها، والصور وحدها لا تثبت الملاءمة أو المقاس الحقيقي. توصية بمقاس حقيقي تحتاج قياسات موثقة من مورّد الملابس وبيانات قياس الطفل. السلة محلية في متصفح كل زائر؛ لا يوجد دفع إلكتروني أو لوحة إدارة أو قاعدة بيانات للطلبات. لتفعيل الطلب، أضف رقم واتساب الصحيح قبل نشر الموقع.
