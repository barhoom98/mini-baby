# MINI BABY

موقع بداية لمتجر **MINI BABY**: واجهة عربية متجاوبة، كتالوج منتجات ومقاسات، بحث وتصنيفات، سلة محفوظة على الجهاز، طلب عبر واتساب، ومعاينة توضيحية للملابس على دمية جانبية.

## تشغيل الموقع

افتح `index.html` في المتصفح. لا يحتاج المشروع إلى تثبيت حزم أو إعداد خادم.

## إضافة معلومات المحل والمنتجات

1. افتح `store.js` وعدّل `currency` ورقم `whatsappNumber` بصيغة دولية مع رمز الدولة، من دون `+` أو مسافات (مثال تنسيقي: `9627XXXXXXXX`).
2. استبدل المنتجات التجريبية في `products` بمعلومات القطع الحقيقية: `name`, `description`, `sizes`, `price`, `color` و`outfit`.
3. أضف صور المنتجات إلى `assets/products/`، ثم ضع مسار كل صورة في الخاصية `image` مثل `assets/products/cotton-set.jpg`. اتركها فارغة مؤقتًا إذا لم توجد صورة. لإضافة صور أخرى للقطعة نفسها (مثل صورة مقرّبة للقماش) ضع مساراتها في `gallery`، وستظهر كصور مصغّرة تحت الصورة الرئيسية.
4. استبدل `assets/logo.svg` بشعار المحل عند توفره. للحفاظ على الاسم الظاهر في الصفحة، عدّل النص `MINI BABY` في `index.html` إذا تغيّر.
5. ارفع التعديلات إلى مستودع GitHub. بعد ربط المستودع بـ Claude Code يمكن طلب تعديل المنتجات أو التصميم من هناك.

الأسعار والمنتجات الموجودة حاليًا **تجريبية** وليست بيانات المحل. السلة محلية في متصفح كل زائر؛ لا يوجد دفع إلكتروني أو لوحة إدارة أو قاعدة بيانات للطلبات. معاينة الدمية توضيحية للألوان والقَصّات وليست تجربة قياس واقعية. لتفعيل الطلب، أضف رقم واتساب الصحيح قبل نشر الموقع.

## ربط Claude Code

استنسخ المستودع من GitHub وافتح مجلده في Claude Code. يحتوي `CLAUDE.md` على إرشادات المشروع ومكان تعديل المنتجات والصور ورقم التواصل.
